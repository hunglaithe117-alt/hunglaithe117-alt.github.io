# Coding Rules

> **When to use:** your project needs its own coding rules and wants one folder to hold them.
>
> **What it answers:** where the project's language, framework, and testing rules live.
>
> Delete this blockquote when filled.

This folder is **project-defined**. The template library ships no rule set: each project writes its own files here and links them from [`README`](../README.md).

Name each file after the rule set it owns — for example `language-style.md`, `framework.md`, or
`testing.md` — and keep one rule set per file.
