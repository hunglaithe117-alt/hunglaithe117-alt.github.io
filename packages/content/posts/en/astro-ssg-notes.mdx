## Notes on building a blog with Astro

This post collects a few things I learned while building a bilingual static blog: routing,
content collections, and keeping the page lightweight.

### Content collections

Each post is an MDX file inside a locale folder. The frontmatter schema is validated with
zod, so a post missing a required field fails the build immediately — exactly what I want.

### Locale routing

Both languages are prefixed in the URL so `hreflang` alternates and feeds stay symmetric:

```ts
export function postPath(lang: Lang, slug: string): string {
  return `/${lang}/posts/${slug}`;
}
```

### Vue islands

Only genuinely interactive pieces ship JavaScript, and they are marked `client:visible` so
they defer until they enter the viewport:

```astro
---
import SmokeIsland from "@blog/ui/SmokeIsland.vue";
---

<SmokeIsland client:visible />
```

### Keeping it light

- Nothing runs on the server at request time: everything is pre-rendered to HTML.
- Images carry intrinsic dimensions to avoid layout shift.
- Only one font file is preloaded; the rest load on demand.

### Closing note

The hard part is not building the site — it is keeping the structure simple enough to still
be readable a few months from now.
