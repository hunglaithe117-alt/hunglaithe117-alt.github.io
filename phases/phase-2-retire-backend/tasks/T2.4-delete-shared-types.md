# T2.4 — Delete the shared API types and dependency wiring

## Why this task exists

`packages/types` holds only the API wire contract: `ViewResponse`, `ContactRequest`, `ApiError`,
`EdgeBindings`, `ApiRoutes`. With no API and no container, the package has no consumer.

## Pre-conditions

- T2.1 and T2.3 have removed the imports that need those types.

## What to do

1. Delete `packages/types/`.
2. Remove `@blog/types` from every `package.json` that depends on it (`apps/web`, `apps/edge`, root if
   present).
3. Remove any `tsconfig` path alias or `pnpm-workspace` entry that references it.
4. Re-resolve the workspace:

   ```bash
   pnpm install
   pnpm --filter @blog/web check
   pnpm --filter @blog/edge build
   ```

## Touches

- `packages/types/**` (delete)
- `apps/web/package.json`, `apps/edge/package.json`, `pnpm-lock.yaml`, `tsconfig.json` if aliased

## Verification

```bash
rg -n "@blog/types|packages/types" . --glob '!**/node_modules/**' --glob '!docs/**' --glob '!phases/**'
# expected: no matches
pnpm install --frozen-lockfile

```

## Self-review

- [ ] No package, import, alias, or lockfile importer references `@blog/types`.
