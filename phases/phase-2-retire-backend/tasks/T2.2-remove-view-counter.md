# T2.2 — Remove the view counter and its e2e contract

## Why this task exists

`ViewCounter.vue` is the last runtime dependency on the API. It must be unmounted and deleted in the same
release that deletes the route, or the page will fetch a 404 on every visit.

## Pre-conditions

- T2.1 prepared; the API route is going away in this release.

## What to do

1. Delete `packages/ui/src/ViewCounter.vue`.
2. Remove its import and `<ViewCounter … client:idle />` mount from
   `apps/web/src/pages/[lang]/posts/[...slug].astro`.
3. Remove the counter's label from both locale dictionaries if it is not shared, keeping the `vi`/`en` key
   sets identical.
4. Delete `e2e/api-contract.spec.ts`; remove the `api` recorder, `views` array, and `**/api/views/**`
   route stub from `e2e/fixtures.ts`. Keep `serve-dist.mjs` and the static journeys.
5. Remove any remaining mention of "view count" or "views" from the post page copy.

## Touches

- `packages/ui/src/ViewCounter.vue` (delete)
- `apps/web/src/pages/[lang]/posts/[...slug].astro`, `apps/web/src/lib/i18n.ts`
- `e2e/api-contract.spec.ts` (delete), `e2e/fixtures.ts`
