# T1.1 — Remove the API surface, service, storage methods, and shared types

## Why this task exists

`POST /api/contact` is the only writer of `contact_messages` and the only consumer of the rate limiter
and the IP hash. Removing it is what makes the rest of the contact code unreachable.

## Pre-conditions

- Q1 answered: option B (remove the feature).
- Q1b answered: keep the table dormant (recommended) rather than dropping it.

## What to do

1. Delete the handler and its route. Evidence:

   ```go
   // router.go — the remaining table
   api.Get("/views/:slug", views.Get)
   api.Get("/healthz", handler.Health)
   // POST /contact removed with handler.NewContactHandler wiring in cmd/server/main.go
   ```

2. Delete `internal/handler/contact.go`, `internal/service/contact.go`, and
   `internal/service/contact_test.go`. Remove the contact constructor wiring from
   `cmd/server/main.go`.

3. Delete `InsertContact` and `CountContactsSince` from `internal/repository/views.go`, and their tests
   from `internal/repository/d1_test.go`. Keep the `views` methods and the D1 client untouched.

4. Remove the contact-only configuration:

   ```go
   // config.go — deleted fields
   // RateLimitPerMinute
   // IPHashSalt (and the SESSION_SECRET fallback)
   ```

   Keep `MAX_BODY_BYTES` as a general guard, and keep `ALLOWED_ORIGINS`.

5. Remove `ContactRequest`, `ContactResponse`, and the `POST /api/contact` entry from `ApiRoutes` in
   `packages/types/index.ts`. Keep `ViewResponse` and `ApiError`.

6. Remove contact cases from `internal/handler/router_test.go` (validation, rate limit, oversize body).
   Keep the views and health cases.

7. Remove the Worker-side contact declarations: the `EMAIL` binding and its comment in
   `apps/edge/cloudflare.config.ts`; `SESSION_SECRET` and `IP_HASH_SALT` (both exist only for the contact
   path); and `EMAIL: SendEmail` from `EdgeBindings` in `packages/types/index.ts`. Deleting the entrypoint
   send path belongs here too: `parseContact`, `sendContactNotification`, `redactEmails`, and
   `CONTACT_TO`/`CONTACT_FROM` in `apps/edge/src/index.ts`.

8. Do **not** delete `apps/api/migrations/0002_contact.sql`. It is applied history.

```bash
# expected: 200 with a count
```
